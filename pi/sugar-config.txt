# PiSugar 3 — CALIBRATED battery curve for Vibb (2026-07-05)
#
# Built from a real full-discharge run on the test rig: fully charged
# (4.19V) -> safe shutdown at 16:13 after 5h04m of continuous Bluetooth
# playback (~0.8W average system draw), voltage logged every 60s by
# vibb-batlog. Percent is defined as REMAINING PLAYTIME: "40%" means
# 40% of the ~5h runtime was left at that voltage under playback load.
#
# Notes on the calibration:
# - Measured UNDER LOAD (~200mA playback incl. IR sag). At true idle the
#   voltage reads a bit higher, so the percentage over-estimates slightly
#   when nothing is playing. For a music box that bias is the right one.
# - 0% is placed at the safe-shutdown point (~3.55V under load), not at
#   the battery-protection cliff (~3.4V) — percent hits 0 when the box
#   actually turns off, as it should.
# - The mid-plateau is real: the cell spends ~70 min between 3.80V and
#   3.75V. That is why the old curves felt "stuck around half".
# - Safe shutdown: with THIS curve, 5% maps to ~3.65V (~15 min left at
#   playback draw). If you keep safe_shutdown_level=5 you shut down a
#   little earlier than the measured run did; set it to 2-3% to match
#   the old behaviour. 5% is the safer, recommended choice.
#

# 1. Edit the config:      sudo nano /etc/pisugar-server/config.json
# 2. Replace/add the line below inside the top-level { ... } object
#    (comma after the previous entry; do NOT paste the # comment lines).
# 3. Restart the server:   sudo systemctl restart pisugar-server
# 4. Verify:               sudo vibb-power status
#
# The server validates the curve: voltages and percentages must both be
