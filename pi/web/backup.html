Where backups go

Backups are stored with restic, which encrypts them before they leave the box. restic reaches your storage through rclone, so any provider rclone supports works — S3, Backblaze B2, Nextcloud/WebDAV, Jottacloud, Drive, Dropbox, SFTP.

On your own computer run rclone config to create a remote (that step also handles providers that need a browser login), then paste the resulting block from rclone.conf below.

This password encrypts the repository. Write it down. Without it the backup cannot be read — not by us, not by anyone. It is stored on the box so backups can run unattended.

Restore

Replaces this box's library, settings, logins and bookmarks with a saved copy, then reboots. The box keeps its own QR code — restoring never brings back an old one — and a Bluetooth speaker has to be paired again.
